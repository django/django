=====================
Optional dependencies
=====================

Some Django features need extra Python packages. Install them with Django
using pip extras:

.. console::

    $ python -m pip install "django[postgresql,redis]"

Where Django requires a minimum version of a package, the extra sets it. Some
packages also need libraries from your operating system. These are listed in
the *System requirements* column.

.. _optional-dependencies-psycopg:

Choosing a ``psycopg`` implementation
-------------------------------------

The ``postgresql`` and ``postgresql-pool`` extras install the pure Python
version of ``psycopg``. It needs the ``libpq`` client library on your system.
To use another implementation, add it to the install command:

* ``psycopg[binary]`` includes ``libpq`` and needs no system libraries. It is
  not available for free-threaded Python or PyPy.
* ``psycopg[c]`` is built against your system ``libpq``. The psycopg project
  recommends it for production.

.. console::

    $ python -m pip install "django[postgresql]" "psycopg[binary]"

See the `psycopg installation documentation
<https://www.psycopg.org/psycopg3/docs/basic/install.html>`_ for details.
