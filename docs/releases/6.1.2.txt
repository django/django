==========================
Django 6.1.2 release notes
==========================

*Expected October 6, 2026*

Django 6.1.2 fixes one data loss issue in 4.0 and several bugs in 6.1.1.

Bugfixes
========

* Fixed a data loss issue in Django 4.0 where :ref:`network rasters
  <gdal-raster-network>` were deleted by GeoDjango when closed.

* Fixed a crash in the exception-handling pipeline where a failing
  ``got_request_exception`` signal receiver could prevent the original
  exception from producing a proper 500 response (:ticket:`21777`).
