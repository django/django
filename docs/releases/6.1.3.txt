==========================
Django 6.1.3 release notes
==========================

*Expected November 3, 2026*

Django 6.1.3 fixes several bugs in 6.1.2.

Bugfixes
========

* Fixed a regression in Django 6.1 where the YAML serializer crashed if passed
  the ``sort_keys`` option (:ticket:`37405`).

* Fixed a regression in Django 6.1 where a :class:`~django.db.models.Value`
  expression with a ``None`` value and an output field other than
  :class:`~django.db.models.JSONField` crashed on SQLite when used in a
  top-level :class:`~django.db.models.JSONField` :lookup:`in` lookup
  (:ticket:`37403`). Using such an expression in an ``IN`` lookup is likely
  unintended, since SQL ``NULL`` cannot match any value.
