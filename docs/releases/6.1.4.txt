==========================
Django 6.1.4 release notes
==========================

*Expected December 1, 2026*

Django 6.1.4 fixes several bugs in 6.1.3.

Bugfixes
========

* Fixed a bug in Django 6.1 where the ``models.E050`` system check did not
  detect mixed ``on_delete`` variants for models with a
  :class:`~django.contrib.contenttypes.fields.GenericRelation`
  (:ticket:`37471`).

* Fixed a bug in Django 6.1 where accessing a non-nullable
  :class:`~django.db.models.ForeignKey` with the
  :attr:`~django.db.models.FETCH_PEERS` fetch mode could return ``None``
  instead of raising :exc:`~django.core.exceptions.ObjectDoesNotExist` when the
  related object had been deleted (:ticket:`37513`).

* Fixed a regression in Django 6.1.3 where a :exc:`RecursionError` from a
  GeoJSON value was not reraised as a
  :exc:`~django.core.exceptions.ValidationError` by the
  :class:`~django.contrib.gis.forms.GeometryField` form field
  (:ticket:`37491`).

* Fixed a regression in Django 6.1 where combining querysets with
  :meth:`.QuerySet.union`, :meth:`.QuerySet.intersection`, or
  :meth:`.QuerySet.difference` could crash when the model's
  :attr:`.Options.ordering` referenced related fields (:ticket:`37505`).

* Added compatibility with :pypi:`pylibmc` 1.8.0 (:ticket:`37529`).
