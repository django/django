==========================
Django 6.0.9 release notes
==========================

*October 6, 2026*

Django 6.0.9 fixes one security issue with severity "low", three security
issues with severity "moderate", and provides a fix for an insufficient
security mitigation in 6.0.8. It also fixes one data loss issue in 4.0.

Bugfixes
========

* Fixed a data loss issue in Django 4.0 where :ref:`network rasters
  <gdal-raster-network>` were deleted by GeoDjango when closed.
